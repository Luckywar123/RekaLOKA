# RekaLOKA FAQ Chatbot

Chatbot FAQ pure frontend (zero cost) untuk website company profile Rekaloka Infra Digital.

## Isi paket

| File | Fungsi |
|------|--------|
| `faq-data.js` | Dataset pertanyaan & jawaban |
| `chatbot.css` | Styling widget (mengikuti tema website) |
| `chatbot.js` | Engine matching + UI chatbot |
| `INTEGRASI.md` | Panduan pasang ke `index.html` |

## Fitur

- Floating chat button (pojok kanan bawah)
- Matching berbasis keyword + skor (tanpa API)
- Quick-reply buttons
- Typing indicator
- Fully responsive
- Bahasa Indonesia

## Cara pakai

Lihat **INTEGRASI.md**.

## Lisensi

Bebas dipakai untuk proyek RekaLOKA.
